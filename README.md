# DocMind

DocMind помогает найти ответ в папке с инструкциями. Задаёшь вопрос и получаешь подходящие разделы с именем файла и номером строки. Если подключить локальную модель Ollama, она составит ответ по найденному тексту.

## Попробовать на примере

В папке проекта открой PowerShell и выполни команду с Python 3.10 или новее:

```powershell
py -m docmind examples "Что показывает история статусов?"
```

Программа найдёт раздел «История статусов» в файле `examples/support.md` на строке 9. Поиск работает на стандартной библиотеке Python.

## Получить ответ от модели

Если Ollama запущена и модель уже установлена, добавь её имя:

```powershell
py -m docmind examples "Что показывает история статусов?" --model qwen3:8b
```

Номера в квадратных скобках связывают ответ со списком источников под ним. Сверь ответ модели с текстом раздела.

## Свои документы

Подставь путь к папке вместо `examples`. DocMind читает файлы `.md` в UTF-8, включая вложенные папки. Разделы отделяются заголовками с символом `#`. Поиск учитывает совпадения слов и отдаёт больший вес заголовкам. Синонимы и другие формы слов могут потребовать переформулировать вопрос.

## Проверка

```powershell
py -m unittest -v
```

Тесты проверяют первый результат для трёх вопросов, ссылку на источник, пустую папку и запрос без совпадений.
